## Critical

1. **15 high advisories.** Direct: `@vercel/blob` 2.5.0 (latest 2.9.0), `shadcn` 4.11.0 (listed in `dependencies`, package.json). Transitive: `zod`, `undici`, `postcss`, `source-map-js`, `@vercel/oidc`, `@vercel/cli-config`, `body-parser`, `brace-expansion`, `browserslist`, `fast-uri`, `ip-address`, `js-yaml`, `@modelcontextprotocol/sdk`. The CI `audit` job runs `npm audit --audit-level=high` (`../.github/workflows/ci.yml:59`) and will fail. Fix: upgrade `@vercel/blob`, move `shadcn` to devDependencies or remove it, then re-audit. Check whether `npm audit fix` covers the rest without `--force`.
2. **Order API has no server-side validation or escaping.** `app/api/orders/route.ts`: no schema (zod is only transitive); `product` and `canvasSize` are not checked against a list (lines 27-37); no size or MIME check; no honeypot; no rate limit. Name, email, child name, requests and address are interpolated into the admin emails unescaped (lines 117-190). Fix: Zod schema, value whitelist, size and type check, `escapeHtml` for every field, honeypot and rate limit.
3. **Upload failures are silent.** `route.ts:73` returns `''` when Blob credentials are missing, and the order is saved anyway (line 89). `components/OrderForm.tsx:47` drops files over 15 MB with no message, while the ultrasound input stays `required` (line 357). Fix: fail the request when upload fails; show a visible error for oversized files.
4. **Mail does not reach the right person.** All sends use `from: 'onboarding@resend.dev'` (lines 118, 147, 176), Resend's test sender. No `reply_to` is set. Fix: verified business domain as sender; `reply_to: orderData.email` on the admin emails. Needs owner input.
5. **No Impressum or Datenschutz.** No pages exist, and `components/Footer.tsx` has no links to them. The site collects personal data and health-related images in Germany.
6. **Mobile navigation does not work.** `components/Header.tsx:59` menu button has no handler, no `aria-expanded`, no `aria-controls`. The nav is `hidden md:flex` (line 35), so phones have no links.
7. **Two price sets still in use.** Set A (visible): `components/PricingTiers.tsx:13, 24-26, 33, 44-46` and `components/OrderForm.tsx:218-220` show 69/89/119 and 30-50. Set B (dropped per DECISIONS.md): `messages/de.json` and `messages/en.json` lines 36, 41-43, 70-72 still hold 9-15 and 29/39/55. No `content/products.ts` exists, so the price has no single source.
