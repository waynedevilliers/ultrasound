# Review: Portraits 4 Life, branch feat/salon77-patterns (2026-11-11)

**Verdict: Needs fixes.** The build fails, the npm audit has a critical and 8 high findings, the order API has no server-side validation or escaping, the order replies do not reach the owner, and the legal pages are missing.

Scope: working tree including uncommitted changes (Footer, Header, Hero, i18n.ts, package.json, package-lock.json, scripts/init-db.js) and ../.github/workflows/ci.yml (uncommitted). Read-only; nothing was changed.

## Critical

1. **Build fails** (`npm run build`, Node 20.17.0). Tailwind/Turbopack `require()`s ESM `magic-string` and `enhanced-resolve` is missing. The running dev server on port 3000 returns HTTP 500 for every route (`.next/dev/logs/next-development.log`). Local dev is broken, so no page could be checked. CI uses Node 22, but CI has no build job, so this is never caught. Fix: pin Node 22 (`.nvmrc`, `engines`), reinstall, add a `build` job to CI.
2. **Vulnerable dependencies.** `npm audit`: 28 findings (1 critical, 8 high). Critical: `next` 9.3.4-canary.0 to 16.4.0 (installed 16.2.9). High: `@vercel/blob`, `shadcn` (direct); `sharp`, `zod`, `postcss`, `brace-expansion`, `@vercel/oidc` (transitive). CI `audit` job runs `--audit-level=high` and would fail. Fix: upgrade `next` to 16.4.6 or later on a branch, then `npm audit fix` and re-check. The lockfile diff is uncommitted.
3. **Unauthenticated customer data endpoint.** `app/api/orders/[id]/route.ts:10` returns the full order row (name, email, shipping address, image URLs) for any sequential ID. Fix: remove it or require owner auth. README documents it, so update README too.
4. **No Impressum or Datenschutz.** No pages exist and `components/Footer.tsx` (lines 19-43) has no links. The site collects personal data and ultrasound images in Germany. Fix: add both pages in DE and EN, link them in the footer, and add a privacy notice at the order form.
5. **No server-side validation or escaping in the order API.** `app/api/orders/route.ts`: no Zod (zod is only transitive), no check on `product` or `canvasSize` values, no upload size or MIME check, no honeypot, no rate limit. Name, email, child name, requests and address are interpolated into HTML emails unescaped (lines 118-190), so the owner's email can carry injected HTML. Fix: Zod schema, whitelist values, size and type check, `escapeHtml` for all email fields.
6. **Orders saved without images, silently.** `route.ts:73` returns `''` when Blob credentials are missing, and the order is saved anyway with no error. `components/OrderForm.tsx:47` silently drops files over 15 MB while the ultrasound input stays `required`, so the form submits without an image. Fix: fail the request when the upload fails; show a visible error for oversized files.
7. **Order replies do not reach the right person.** All mail is sent `from: 'onboarding@resend.dev'` (lines 118, 147, 176), which is Resend's test sender, and no `reply_to` is set. Replying to the customer confirmation or the admin email goes nowhere useful. Fix: verified business domain as sender, `reply_to: orderData.email` on the admin emails. Needs owner input (see client list).

## Important

8. **Security headers absent.** `next.config.ts:4-6` is empty; `lib/security-headers.ts` does not exist. Add CSP, HSTS, X-Content-Type-Options, Referrer-Policy, Frame-Options, Permissions-Policy in `headers()`.
9. **Error details leak.** `app/api/orders/route.ts:205` returns the internal error message to the client.
10. **Upload URLs are public and guessable.** `route.ts:66` builds the blob path from `Date.now()` and the client's `file.name` (unsanitised). Health-related images are publicly readable. Fix: random blob names, sanitised names, retention policy.
11. **Per-page metadata missing.** Only the root metadata exists (`app/layout.tsx:25-28`). Every page shares one title and description. No canonical, hreflang, JSON-LD, `robots.ts` or `sitemap.ts` in the repo.
12. **No `lang` attribute.** `app/layout.tsx:34` `<html>` has none.
13. **Mobile navigation does not work.** `components/Header.tsx:59` menu button has no handler, and the nav is `hidden md:flex` (line 35), so mobile has no nav links. `#pricing` and `#contact` (lines 42, 45) do not exist on `/order`.
14. **Gallery not keyboard-accessible.** `components/Gallery.tsx:24,36` are `div onClick` with no role, tabIndex or key handler. Images have no `sizes` (lines 27, 39).
15. **Form labels not linked.** `components/OrderForm.tsx`: 15 `<label>` elements, 0 `htmlFor`/`id`. Error box (line 157) is not announced.
16. **Text hardcoded in components.** PricingTiers.tsx:10-50, OrderForm.tsx, Header.tsx, Footer.tsx, Hero.tsx use inline DE/EN ternaries. `messages/*.json` (66 keys each, in parity) is loaded only by `i18n.ts:12` and used by no component. The `content/` folder from the plan does not exist.
17. **Prices in four places, two sets.** `PricingTiers.tsx:24-26,44-46` and `OrderForm.tsx:218-220` show 69/89/119. `messages/de.json` and `en.json` lines 36-43 and 70-72 still hold the dropped set (9-15, 29/39/55), which DECISIONS.md says was removed. No `content/products.ts`.
18. **Contrast below 4.5:1** (computed from Tailwind v4 default values; colors are frozen by DECISIONS, so this needs the owner's decision): white on `bg-pink-500` (`Hero.tsx:44`) about 3.5:1; `text-gray-500` on `bg-gray-900` (`Footer.tsx:41`) about 3.9:1; `text-pink-600` on `bg-pink-50` (`Header.tsx:53`) about 4.2:1.
19. **Body font broken.** `app/globals.css:24` `--font-sans: var(--font-sans);` refers to itself; body renders in the default serif. Open in DECISIONS.md.
20. **Fonts loaded but unused.** `app/layout.tsx:12` `geistMono` is loaded and never used (also a lint warning).
21. **Lint warnings and build warning.** 7 lint warnings (`app/api/orders/[id]/route.ts:17`, `app/api/orders/route.ts:141,170,190`, `app/layout.tsx:12`, `OrderInfo.tsx:94`, `PricingTiers.tsx:4`). Build prints the Next 16 `middleware` deprecation warning (`middleware.ts`). Project rule: zero warnings.
22. **Routing conflict.** `middleware.ts:6` default locale is `de` and `:14` matches `/`, so `app/page.tsx:4` (`redirect('/en')`) is never reached. README says German is default. Remove the dead page and fix the default.
23. **Order page h1 is bilingual.** `app/[locale]/order/page.tsx:16,20` show "Bestellen / Order" and mixed text in both locales.
24. **Test setup does not match the rules.** `jest` is configured, no test files exist, and `npm test` only passes with `--passWithNoTests` (CI uses that flag). CLAUDE.md asks for Vitest and Playwright; there is no `e2e/`. No essential tests exist.
25. **Dead code and dependency hygiene.** `lib/db.ts` `initializeDatabase` and `getOrder` are unused; `lib/db-init.sql` duplicates the schema. `scripts/init-db.js` uses `dotenv`, which is not declared. `shadcn` sits in `dependencies` (package.json:29). `ts-node` is unused. Two Postgres clients are declared (`@vercel/postgres`, `@neondatabase/serverless`). `components/ui/tabs.tsx` appears unused.
26. **Stale and missing docs.** `README.md` says Node 18+ (build fails on 20.17), documents the public GET endpoint, and uses `feature/` branch names. No `.env.example`. `.gitignore` `.env*` would ignore one anyway; add a `!.env.example` exception. Footer copyright is 2024 (`Footer.tsx:12-13`).
27. **Plan and CI gaps.** `portraits4life-upgrade-plan.md` is missing from the repo. The uncommitted CI has no build and no e2e job.
